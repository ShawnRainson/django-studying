основной urls.py:

from django.urls import include, path

urlpatterns = [
    path('admin/', admin.site.urls),
    path("", include("blog.urls")),
]

blog/urls.py:
from django.urls import path
from . import views

urlpatterns = [
    path("hello/", views.hello),
    path("about/", views.about),
]

🔥 Финальный челлендж

Браузер отправляет запрос на локальный сервер
Локальный сервер принимает запрос и передаёт его Django
Django видит что указан путь /about/
Django проверяет список путей, находит нужный
Заетм он запрашивает view по этому пути
После чего он отправляет HTTP-ответ браузеру с кодом страницы
Браузер показывает страницу.
